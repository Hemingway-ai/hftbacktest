# 统计分析与绩效指标详解

## 一、概述

HftBacktest 提供了完整的统计分析框架，用于评估回测策略的绩效。核心模块位于 `hftbacktest.stats`。

---

## 二、核心类

### 2.1 LinearAssetRecord

用于线性合约 (USDT 本位) 的回测结果分析。

```python
from hftbacktest.stats import LinearAssetRecord

# 加载回测结果
data = np.load('result.npz')['0']

# 创建分析对象
record = LinearAssetRecord(data)
```

### 2.2 InverseAssetRecord

用于反向合约 (币本位) 的回测结果分析。

```python
from hftbacktest.stats import InverseAssetRecord
```

---

## 三、分析流程

### 3.1 标准流程

```python
from hftbacktest.stats import LinearAssetRecord

# 1. 加载数据
data = np.load('result.npz')['0']

# 2. 创建记录对象
record = LinearAssetRecord(data)

# 3. 重采样 (可选)
resampled = record.resample('5m')  # 5 分钟采样

# 4. 计算统计指标
stats = resampled.stats(
    book_size=1_000_000,           # 资金规模 (可选)
    trading_days_per_year=365      # 加密货币用 365
)

# 5. 输出结果
stats.summary()
```

### 3.2 重采样频率

| 频率 | 说明 |
|------|------|
| `'1m'` | 1 分钟 |
| `'5m'` | 5 分钟 |
| `'15m'` | 15 分钟 |
| `'1h'` | 1 小时 |
| `'1d'` | 1 天 |

## 四、绩效指标详解

### 4.1 收益指标

#### Return (总收益率)

$$Return = \frac{Equity_{end} - Equity_{start}}{BookSize}$$

```python
from hftbacktest.stats.metrics import Ret

# 计算总收益率
ret = Ret(book_size=1_000_000).compute(df, context)
```

#### AnnualReturn (年化收益率)

$$AnnualReturn = Return \times \frac{TradingDaysPerYear}{TotalDays}$$

```python
from hftbacktest.stats.metrics import AnnualRet

# 加密货币用 365 天
annual_ret = AnnualRet(
    book_size=1_000_000,
    trading_days_per_year=365
).compute(df, context)
```

### 4.2 风险指标

#### MaxDrawdown (最大回撤)

$$MaxDrawdown = \max(Equity_{peak} - Equity_{trough})$$

```python
from hftbacktest.stats.metrics import MaxDrawdown

mdd = MaxDrawdown(book_size=1_000_000).compute(df, context)
```

#### Sharpe Ratio (夏普比率)

$$Sharpe = \frac{E[R_p] - R_f}{\sigma_p} \times \sqrt{c}$$

其中 `c = samples_per_day × trading_days_per_year`

```python
from hftbacktest.stats.metrics import SR

# 加密货币无风险利率通常设为 0
sharpe = SR(trading_days_per_year=365).compute(df, context)
```

#### Sortino Ratio (索提诺比率)

只考虑下行风险的夏普比率：

$$Sortino = \frac{E[R_p]}{\sigma_{downside}} \times \sqrt{c}$$

```python
from hftbacktest.stats.metrics import Sortino

sortino = Sortino(trading_days_per_year=365).compute(df, context)
```

### 4.3 效率指标

#### ReturnOverMDD (收益/回撤比)

$$ReturnOverMDD = \frac{Return}{MaxDrawdown}$$

```python
from hftbacktest.stats.metrics import ReturnOverMDD

romdd = ReturnOverMDD().compute(df, context)
```

#### ReturnOverTrade (收益/交易额比)

$$ReturnOverTrade = \frac{Return}{TradingValue}$$

```python
from hftbacktest.stats.metrics import ReturnOverTrade

rot = ReturnOverTrade().compute(df, context)
```

### 4.4 交易指标

#### NumberOfTrades (交易次数)

```python
from hftbacktest.stats.metrics import NumberOfTrades, DailyNumberOfTrades

total_trades = NumberOfTrades().compute(df, context)
daily_trades = DailyNumberOfTrades().compute(df, context)
```

#### TradingVolume (交易量)

```python
from hftbacktest.stats.metrics import TradingVolume, DailyTradingVolume

total_vol = TradingVolume().compute(df, context)
daily_vol = DailyTradingVolume().compute(df, context)
```

#### TradingValue (交易额 / 换手率)

```python
from hftbacktest.stats.metrics import TradingValue, DailyTradingValue

# 交易额
total_value = TradingValue().compute(df, context)

# 换手率 (需要 book_size)
turnover = DailyTradingValue(book_size=1_000_000).compute(df, context)
```

### 4.5 持仓指标

#### MaxPositionValue (最大持仓价值)

```python
from hftbacktest.stats.metrics import MaxPositionValue

max_pos = MaxPositionValue().compute(df, context)
```

#### MeanPositionValue (平均持仓价值)

```python
from hftbacktest.stats.metrics import MeanPositionValue

mean_pos = MeanPositionValue().compute(df, context)
```

#### MaxLeverage (最大杠杆)

```python
from hftbacktest.stats.metrics import MaxLeverage

max_lev = MaxLeverage(book_size=1_000_000).compute(df, context)
```

## 六、自定义指标

### 6.1 创建自定义指标类

```python
from hftbacktest.stats.metrics import Metric

class ProfitFactor(Metric):
    """盈亏比 = 总盈利 / 总亏损"""

    def __init__(self, name=None):
        self.name = name if name is not None else 'ProfitFactor'

    def compute(self, df, context):
        equity = df['equity_wo_fee'] - df['fee']
        pnl = equity.diff()

        gains = pnl.filter(pnl > 0).sum()
        losses = abs(pnl.filter(pnl < 0).sum())

        return {self.name: gains / losses if losses > 0 else float('inf')}
```

### 6.2 使用自定义指标

```python
stats = record.resample('5m').stats(
    book_size=1_000_000,
    extra_metrics=[ProfitFactor()]
)
```

## 八、完整示例

### 8.1 基本分析

```python
import numpy as np
from hftbacktest.stats import LinearAssetRecord

# 加载结果
data = np.load('result.npz')['0']

# 分析
stats = (
    LinearAssetRecord(data)
    .resample('5m')
    .stats(book_size=2_500_000)
)

# 输出摘要
stats.summary()
```

**输出示例**：
```
SR: 2.35
Sortino: 3.12
Return: 0.0456
AnnualReturn: 0.1234
MaxDrawdown: 0.0234
ReturnOverMDD: 1.95
DailyNumberOfTrades: 1234.56
DailyTurnover: 45.67
MaxPositionValue: 1.23M
```

### 8.2 多参数比较

```python
# 比较不同参数的策略结果
for half_spread in [0.5, 1.0, 1.5, 2.0]:
    data = np.load(f'result_spread_{half_spread}.npz')['0']
    stats = (
        LinearAssetRecord(data)
        .resample('5m')
        .stats(book_size=1_000_000)
    )
    print(f"half_spread={half_spread}: SR={stats['SR']:.2f}, MDD={stats['MaxDrawdown']:.4f}")
```

## 九、常见问题

### Q1: book_size 如何设置？

`book_size` 表示策略的资金规模，用于将绝对值转换为百分比：
- 如果不设置，指标显示原始值
- 如果设置，Return/MaxDrawdown 等显示为百分比

### Q2: trading_days_per_year 用 252 还是 365？

- **传统金融市场**: 252 (交易日)
- **加密货币市场**: 365 (7×24 小时)

### Q3: 采样频率如何选择？

| 频率 | 适用场景 |
|------|----------|
| 1m | 高频策略分析 |
| 5m | 通用做市策略 |
| 15m | 中频策略 |
| 1h | 低频策略 |

### Q4: SR 为负值是什么意思？

负 SR 表示策略亏损，即平均收益为负。绝对值越大，亏损越严重。
