# HftBacktest 系统架构分析

## 📋 项目概览

- **项目名称**: HftBacktest（高频交易回测框架）
- **核心语言**: Rust（引擎）+ Python（工具）
- **项目版本**: Python 2.4.4 / Rust 0.9.4
- **用途**: 高频交易(HFT)和市场做市策略的回测与实时交易框架

## 🏗️ 核心模块详解

### 1️⃣ 回测引擎核心 (`hftbacktest/src/`)

| 模块 | 文件 | 功能 |
|------|------|------|
| **事件系统** | `backtest/evs.rs` | 事件驱动的回测循环核心，处理所有事件分发 |
| **订单管理** | `backtest/order.rs` | 订单生命周期管理(提交→待成交→成交→取消) |
| **账户状态** | `backtest/state.rs` | 头寸、余额、手续费、P&L追踪 |
| **数据读取** | `backtest/data/reader.rs` | NPY格式市场数据读取 |
| **手续费模型** | `backtest/models/fee.rs` | 多种手续费计算方式 |
| **延迟模型** | `backtest/models/latency.rs` | Feed延迟和Order延迟模型 |
| **队列模型** | `backtest/models/queue.rs` | 订单成交概率预测(基于队列位置) |
| **市场深度** | `depth/hashmap.rs` | HashMap实现(低内存占用) |
| **市场深度** | `depth/btree.rs` | BTree实现(有序访问优化) |
| **市场深度** | `depth/roivector.rs` | ROI向量实现(高频场景优化) |
| **数据融合** | `depth/fuse.rs` | 多个不同频率数据流的合并 |
| **本地处理器** | `backtest/proc/local.rs` | 单资产本地订单处理 |
| **L3处理器** | `backtest/proc/l3_local.rs` | Market-By-Order L3深度处理 |

### 2️⃣ Python绑定与工具 (`py-hftbacktest/hftbacktest/`)

#### 📊 统计分析(`stats/`)

| 文件 | 功能 |
|------|------|
| `stats.py` | 统计分析框架(收益率、波动率等) |
| `metrics.py` | **关键性能指标** |
| `utils.py` | 时间序列重采样和聚合工具 |

**Metrics包括**:
- Sharpe Ratio (夏普比率)
- Sortino Ratio (索提诺比率)
- 总收益率
- 最大回撤
- 收益/回撤比
- 交易日统计
- 最大持仓价值

### 3️⃣ 数据收集工具 (`collector/`)

**功能**: 从交易所HTTP API实时收集OHLCV和Orderbook快照数据

**支持的交易所**:
- Binance现货、USDT期货、COIN-M期货
- Bybit永续期货
- HyperLiquid

**核心能力**:
- 多线程并发请求
- 自适应限流(Throttler)
- gzip压缩存储
- 时间对齐

### 4️⃣ 实时连接器 (`connector/`)

**功能**: 与交易所WebSocket通信的网关

**架构**:
```
Multiple Trading Bots (via Iceoryx2 IPC)
              ↓
    Connector (main process)
      ↙      ↓      ↘
  REST   WebSocket  WebSocket
  API   (Market)   (Account)
  ↓       ↓          ↓
Binance / Bybit / HyperLiquid
```

**关键能力**:
- 实时订单提交/取消
- 实时行情和账户推送
- 多bot共享一个Connector
- Bincode序列化通信

## 📊 核心数据结构

### 事件数据类型 (`event_dtype`)
```python
{
    'ev': uint8,           # 事件类型标志
    'exch_ts': int64,      # 交易所时间戳
    'local_ts': int64,     # 本地时间戳
    'px': float64,         # 价格
    'qty': float64,        # 数量
    'order_id': uint8,     # 订单ID
    'ival': int64,         # 整数值
    'fval': float64        # 浮点值
}
```

### 订单结构 (`order_dtype`)
```python
{
    'qty': float64,           # 订单数量
    'leaves_qty': float64,    # 剩余数量
    'exec_qty': float64,      # 已执行数量
    'price_tick': float64,    # 价格刻度
    'order_id': uint8,        # 订单ID
    'status': int,            # 订单状态
    'side': int,              # 买卖方向 (BUY/SELL)
    'time_in_force': int      # 时间力度 (GTC/FOK/IOC)
}
```
