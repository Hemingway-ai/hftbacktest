## 2. 整体架构说明

### 2.1 模块定位

`hftbacktest-derive` 是一个 **proc-macro crate**（`proc-macro = true`），用于给主库 `hftbacktest` 提供编译期代码生成能力，减少样板代码与组合分支手写成本。

### 2.2 核心能力

1. `#[derive(NpyDTyped)]`
- 面向结构体字段自动生成 `NpyDTyped::descr()` 实现。
- 将 Rust 字段类型映射为 NPY dtype 描述（包含大小端前缀），供 `backtest/data/npy` 读写层使用。

2. `build_asset!(...)`
- 编译期展开多维模型组合（资产类型、延迟模型、队列模型、交易所模型、手续费模型）的匹配分支。
- 在展开分支中自动组装 `Reader + LocalProcessor + Exchange Processor + State + MarketDepth`，返回完整 `Asset`。
- 该宏本质是“回测资产构建模板生成器”，用于减少大量组合枚举下的重复构建代码。

### 2.3 与主工程的关系

- 依赖方向：`hftbacktest` -> `hftbacktest-derive`。
- 作用阶段：编译期（语法树解析与代码生成），非运行时逻辑模块。
- 影响面：数据类型描述自动化、复杂资产构建分支自动化。


## 4. 逐文件映射表（完整相对路径）

- `hftbacktest-derive/Cargo.toml`：定义过程宏包元数据，启用 `proc-macro = true`，并引入 `syn/quote/proc-macro2`。
- `hftbacktest-derive/src/lib.rs`：
  - 实现 `NpyDTyped` 派生宏，自动生成 NPY 字段描述。
  - 实现 `build_asset` 宏，解析输入并生成多模型组合的 `match` 构建代码。
  - 定义宏输入解析结构（如 `EnumArgs`、`BuildAssetInput`）与解析逻辑。
