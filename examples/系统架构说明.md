# Examples 模块架构说明

> 参考根目录 `系统架构分析.md`，本文件聚焦 `examples/` 目录。

## 1. 模块定位

`examples/` 是项目的教学与样例入口，目标是：

1. 演示从市场数据到回测策略的完整使用流程。
2. 提供不同交易所/合约类型的可运行最小示例。
3. 提供可直接复现的样例数据（`.gz`）与 Notebook 教程。

## 3. 整体结构

### 3.1 内容分层

1. `入门与专题教程层`（根目录 Notebook）
- 从 `Getting Started` 到延迟、队列模型、多市场、L3 等高级主题。

2. `可执行脚本层`（`example*.py`）
- 提供可直接运行的最小可复用模板，适合改造成自己的策略脚本。

3. `样例数据层`（`spot/usdm/cm/bybit/hyperliquid/mexc`）
- 提供按交易所与品种分类的 `.gz` 行情样本，供转换与回测演示使用。

### 3.2 典型使用流

1. 先运行 `Getting Started.ipynb` 或 `example.py` 熟悉 API。
2. 用交易所专属脚本（如 `example_bybit.py`）把 `.gz` 转换为回测输入。
3. 在专题 Notebook 中验证策略建模（队列、延迟、多市场、GLFT 等）。
4. 迁移到自己的数据与参数，形成可复现实验。

## 4. 逐文件详细说明

### 4.1 Notebook 导读（详细）

| 文件 | 详细介绍 |
|---|---|
| `examples/Getting Started.ipynb` | 入门总教程。按顺序覆盖 `BacktestAsset` 配置、行情推进、下单/撤单、等待回报、仓位与权益查看、BBO 绘图与统计输出，是最完整的 API 起步路径。 |
| `examples/Working with Market Depth and Trades.ipynb` | 专注“盘口与成交访问”。对比 `HashMapMarketDepthBacktest` 与 `ROIVectorMarketDepthBacktest`，展示 3 档盘口打印、ROI 向量访问、最近成交读取与滚动 VWAP。 |
| `examples/Data Preparation.ipynb` | 数据预处理主教程。演示从 `collector` 原始 `.gz` 到标准化 `.npz`，并给出初始快照/日末快照构建流程，同时包含 Tardis 数据接入范式。 |
| `examples/Order Latency Data.ipynb` | 延迟建模教程。说明如何从 feed latency 生成 `req_ts/exch_ts/resp_ts` 结构化订单延迟数据，并对负延迟等异常进行检查。 |
| `examples/Impact of Order Latency.ipynb` | 研究订单延迟对策略绩效影响。对比由 feed latency 推导、实盘采样、放大延迟等多种场景下的回测结果差异。 |
| `examples/Probability Queue Models.ipynb` | 队列概率模型对比实验。围绕同一策略替换不同 queue model（如 power/log 变体），比较成交模拟与绩效统计差异。 |
| `examples/Queue-Based Market Making in Large Tick Size Assets.ipynb` | 大 tick 资产做市。分 `Book Pressure`、`Trade Impulse`、`Pure Queue-Based Model` 三步，展示队列位置与微观结构信号如何驱动报价。 |
| `examples/Fusing Depth Data.ipynb` | 深度融合教程。先比较 `depth@0ms` 与 `bookTicker` 的 BBO 更新差异，再演示 `convert_fuse` 生成融合数据并做前后回测对比。 |
| `examples/Accelerated Backtesting.ipynb` | 加速回测教程。解释简化填单条件、预计算数据结构与预处理流程，最后与完整回测做结果对比并讨论精度-速度权衡。 |
| `examples/High-Frequency Grid Trading.ipynb` | 高频网格基础实现。包含 Plain 版本、带 skew 版本（弱/强）以及多资产扩展，适合作为策略骨架。 |
| `examples/High-Frequency Grid Trading - Simplified from GLFT.ipynb` | 从 GLFT 简化出的网格策略。提供 Binance/Bybit 两套实验段，强调以更低复杂度近似 GLFT 思路。 |
| `examples/High-Frequency Grid Trading - Comparison Across Other Exchanges.ipynb` | 跨交易所对比实验。统一策略参数框架下比较 Binance Futures 与 Bybit 的回测表现，包含 latency 偏移与统计汇总。 |
| `examples/GLFT Market Making Model and Grid Trading.ipynb` | GLFT 专题。先推导/标定交易强度与波动，再实现 GLFT 做市器并引入网格扩展，最后给出参数调整与参考文献。 |
| `examples/Market Making with Alpha - Order Book Imbalance.ipynb` | Alpha 做市系列之一，核心是 OBI（盘口失衡）信号构造与策略集成，并附后续年份回测更新结果。 |
| `examples/Market Making with Alpha - Basis.ipynb` | Alpha 做市系列之二，核心是基差因子（期现关系）驱动报价偏移，展示从因子到回测统计的完整链路。 |
| `examples/Market Making with Alpha - APT.ipynb` | Alpha 做市系列之三。基于 APT 扩展到多因子定价，包含网格融合、多元回归（MLR）及“综合定价框架”章节。 |
| `examples/Pricing Framework.ipynb` | 研究型定价框架。整合多资产收益、订单簿特征、加速回测管线，并按多个币种给出分资产结果与长区间回测。 |
| `examples/Making Multiple Markets - Introduction.ipynb` | 多市场做市前置教程。用简化数学/仿真先解释“多市场联动做市”的核心概念与建模直觉。 |
| `examples/Making Multiple Markets.ipynb` | 多市场做市完整版。包含延迟影响、简化模型与“更多资产”扩展，展示组合化 market making 的实现路径。 |
| `examples/Integrating Custom Data.ipynb` | 自定义数据接入教程。示例将外部 spot 价格等自有信号与订单簿/成交流结合，接入策略回测循环。 |
| `examples/Level-3 Backtesting.ipynb` | L3 回测示例。展示使用 `hftbacktest.data.utils.databento` 处理逐笔委托级数据并接入策略。 |

## 5. 与其它模块关系

1. `examples` 依赖 `hftbacktest` / `py-hftbacktest` 提供的回测与数据转换 API。
2. `.gz` 样例数据通常对应 `collector` 采集产物形态，用于演示数据到回测的衔接。
3. 示例代码可作为连接 `connector`（实盘）前的策略验证基线。
