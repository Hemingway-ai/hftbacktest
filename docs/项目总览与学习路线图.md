# HftBacktest 项目总览与学习路线图

## 一、项目定位

**HftBacktest** 是一个专为高频交易 (HFT) 和做市策略设计的**回测与实盘一体化框架**。与传统回测工具不同，它在三个关键维度上追求真实模拟：

1. **行情延迟 (Feed Latency)**：模拟市场数据从交易所到达策略的时间差
2. **订单延迟 (Order Latency)**：模拟订单从策略提交到交易所确认的时间差
3. **队列位置 (Queue Position)**：模拟限价单在订单簿中的排队位置对成交概率的影响

### 核心优势

| 优势 | 说明 |
|------|------|
| **Rust 核心引擎** | 纳秒级事件处理，C++ 级别性能 |
| **Python JIT 策略** | Numba @njit 编译，开发效率与执行性能兼顾 |
| **回测/实盘统一** | 同一套策略代码无需修改即可在两种环境运行 |
| **Tick-by-Tick 回放** | 基于逐笔数据的精确市场模拟 |
| **可插拔模型** | 延迟、队列、手续费模型均可独立配置和替换 |

```python
@njit
def strategy(hbt):
    while hbt.elapse(1_000_000_000) == 0:  # 每秒执行
        depth = hbt.depth(0)
        mid_price = (depth.best_bid + depth.best_ask) / 2.0
        # ... 策略逻辑

asset = (
    BacktestAsset()
    .data(['data.npz'])
    .linear_asset(1.0)
    .tick_size(0.1)
    .lot_size(0.001)
)

hbt = ROIVectorMarketDepthBacktest([asset])
strategy(hbt)
hbt.close()
```
